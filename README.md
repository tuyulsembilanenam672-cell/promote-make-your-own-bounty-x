Entry for [Promote make.fun's make-your-own-bounty post on X](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01) ($250, top 50 places).

The entry is one X post that quotes make.fun's make-your-own-bounty post, with a photo of its own, the line "Make your own bounty on @makefunai: https://make.fun/sponsor/new", and play code `makefun-poppy-zinnia-doughnut`:

https://x.com/TSembilane56550/status/2124984889338626509

Places go by the post's replies + reposts + quotes at the deadline. The program in this repo does only what the bounty asks: `main.ts` (Node 22) reads `POST.json` from the repository root, checks it names a real X post, and copies it byte-for-byte to the output directory. The house reads the post itself.
